## 🚀 Como Instalar o Projeto Agora?

### 🎯 Método Recomendado (90% dos usuários)

```bash
# 1. Clone o repositório
git clone https://github.com/govinda777/GovindaSystems.git
cd GovindaSystems

# 2. Execute o script de instalação rápida
./install-fast.sh

# 3. Escolha no assistente:
#    - Opção 1: pnpm (2-3x mais rápido)
#    - Limpar cache: n (mais rápido, exceto primeira vez)

# 4. Configure ambiente
cd src/web
cp .env.example .env.local
# Edite .env.local com suas chaves

# 5. Inicie desenvolvimento
npm run dev  # ou: pnpm dev

# 6. Acesse
# http://localhost:3000
```

**Tempo esperado:** 2-5 minutos (instalação + config)
