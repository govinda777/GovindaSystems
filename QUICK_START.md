## 🚀 Instalação Ultra Rápida

```bash
# 1. Clone (se ainda não fez)
git clone https://github.com/govinda777/GovindaSystems.git
cd GovindaSystems

# 2. Instale RÁPIDO (escolha opção 1 = pnpm)
./install-fast.sh

# 3. Configure
cd src/web
cp .env.example .env.local
# Edite .env.local com suas chaves

# 4. Execute
npm run dev
```

**Abra:** http://localhost:3000

## 🛠️ Comandos Úteis

```bash
# Desenvolvimento
npm run dev          # Inicia servidor dev
npm run build        # Build de produção
npm run start        # Inicia servidor prod
npm run lint         # Verifica código
npm run test         # Executa testes

# Instalação
./install-fast.sh    # Instalação otimizada
npm install          # Instalação padrão
pnpm install         # Instalação com pnpm

# Limpeza
npm run clean        # Remove node_modules
npm run clean:all    # Remove tudo + cache
```

## 🐛 Problemas?

```bash
# Reinstalação limpa
cd src/web
rm -rf node_modules .next
npm cache clean --force
npm install

# Ou use o script otimizado
cd ../..
./install-fast.sh  # escolha limpar cache (y)
```
